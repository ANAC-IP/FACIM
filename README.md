# FACIM 2026 — versão actualizada

Esta versão foi actualizada a partir do documento `Facim 2026_2.docx` fornecido pelo utilizador.

Inclui:
- 8 espécies: Leão, Leopardo, Rinoceronte, Elefante, Búfalo, Impala, Dugongo e Raias.
- Página individual `details.html?id=...` para cada espécie.
- Descrição, função ecológica, áreas de ocorrência e valor turístico/económico.
- Dados do censo 2018–2025 para elefante, búfalo e impala.
- Infográficos presentes no documento.
- Design responsivo para computador, tablet e telemóvel.
- Estrutura pronta para publicação em `/facim2026/` dentro do domínio da ANAC.

Publicação:
copiar o conteúdo desta pasta para:
`/var/www/html/anac.gov.mz/facim2026/`

URL prevista:
`https://www.anac.gov.mz/facim2026/`
